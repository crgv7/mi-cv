Clasificación de Narrativas y Detección de Desinformación

Proceso de postulación a Beca de Excelencia (Colombia)

Ver Repositorio en GitHub

Diseño y desarrollo de un pipeline de procesamiento de lenguaje natural (NLP) para la identificación automatizada de desinformación y clasificación de narrativas en medios digitales. El sistema utiliza un enfoque híbrido que combina lógica difusa para el etiquetado inicial y modelos predictivos para la clasificación final.

Metodología y Técnicas

Etiquetado Híbrido

Implementación de un agente basado en Lógica Difusa (Fuzzy Logic) y léxicos especializados para generar etiquetas preliminares en grandes volúmenes de datos no estructurados.

Modelado Predictivo

Entrenamiento y validación de un modelo de Regresión Logística optimizado para clasificación binaria y multiclase.

Ingeniería de Datos

Aplicación de técnicas de Balanceo Sintético (SMOTE) para mitigar el sesgo en el set de datos, debido a la baja representatividad de noticias falsas frente a las reales.

Auditoría de Discrepancias

Creación de un umbral de sospecha ajustable, permitiendo calibrar la sensibilidad del modelo para reducir falsos negativos en la detección de noticias sensibles.

Stack Tecnológico

Python Scikit-learn Imbalanced-learn (SMOTE) Pandas NLTK Spacy

Logros Técnicos

  • Automatización del proceso de auditoría de noticias, reduciendo la dependencia de revisión humana en un primer nivel de filtrado.
  • Implementación de un sistema escalable capaz de procesar y clasificar miles de registros con alta precisión a pesar del desbalance inherente en los datos de origen.
