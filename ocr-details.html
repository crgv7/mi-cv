Invoice OCR Extractor

(YOLO + PaddleOCR)

Este proyecto es una herramienta avanzada para la extracción automatizada de datos de facturas en formato PDF. Utiliza una arquitectura híbrida que combina la detección de objetos por Inteligencia Artificial para localizar campos específicos y motores de OCR de última generación para la lectura de texto.

Características

Segmentación Inteligente

Utiliza YOLO para identificar áreas clave (RUC, Fecha, Totales, Items, etc.).

OCR de Alta Precisión

Implementa PaddleOCR con soporte para español.

Pre-procesamiento

Conversión de PDF a imagen de alta resolución y re-escalado dinámico.

Validación Automática

Limpieza y validación de campos críticos mediante regex (RUC, Claves de Acceso).

Contenerizado

Listo para desplegarse mediante Docker, optimizado para ejecución en CPU.

Tecnologías Utilizadas

Python 3.10 Ultralytics YOLO PaddleOCR PyMuPDF (fitz) OpenCV Docker Docker Compose

Estructura del Proyecto

  • input/: Carpeta para archivos PDF a procesar.
  • output/: Carpeta para resultados JSON e imágenes.
  • models/: Directorio para el modelo entrenado (best.pt).
  • main.py: Script principal del pipeline.
  • dockerfile: Configuración de imagen Docker.

Instalación y Uso

Opción 1: Con Docker (Recomendado)

# 1. Asegura el modelo best.pt en models/
# 2. Coloca facturas en input/
# 3. Ejecuta:
docker-compose up --build

Opción 2: Instalación Local

# Crear entorno virtual
python -m venv venv
source venv/bin/activate

# Instalar dependencias
pip install -r requirements.txt

# Ejecutar script
python main.py --model ./models/best.pt --input ./input --output ./output

Formato de Salida

El sistema genera un archivo JSON por cada factura procesada:

{
    "DIRECCION MATRIZ": "...",
    "NOMBRE": "...",
    "FECHA": "DD/MM/YYYY",
    "RUC": "1792879485001",
    "RUC_CLIENTE": "...",
    "ITEM": [
        "CANTIDAD", "DESCRIPCION", "PRECIO", "..."
    ],
    "TOTAL": "...",
    "CLAVE ACCESO": "..."
}

Notas de Implementación

  • Optimizado para ejecución en CPU sin sacrificar precisión.
  • Validación de RUC y Claves de Acceso específica para Ecuador (SRI).
  • Arquitectura modular que permite intercambiar motores de OCR fácilmente.
