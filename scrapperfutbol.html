Scraper de Estadísticas de Fútbol

Temporada 2025-2026

Este script automatiza la extracción de datos deportivos desde portales web dinámicos. Está diseñado específicamente para navegar de forma indetectable y extraer múltiples estructuras de datos (tablas) en una sola ejecución.

Lo que hace el código actualmente

Navegación Sigilosa

Utiliza undetected-chromedriver para evitar ser bloqueado por sistemas de seguridad perimetral durante la sesión.

Detección Dinámica

El script localiza y contabiliza todas las tablas de datos presentes en la página (ej. 17 tablas encontradas en la temporada 2025-2026).

Procesamiento con Pandas

Convierte el contenido HTML de las tablas en estructuras de datos (DataFrames) para su posterior exportación.

Compatibilidad con Windows

Incluye lógica para gestionar el cierre del navegador y mitigar errores de controlador (WinError 6) comunes en este sistema operativo.

Tecnologías Utilizadas

Python Selenium Undetected-Chromedriver Pandas Windows Terminal (PowerShell)

Estado del Proyecto

Actualmente, el script completa el ciclo de vida:

  • Apertura del navegador.
  • Escaneo de tablas por temporada.
  • Intento de guardado en CSV.
  • Cierre seguro de la sesión.

Este proyecto es parte de mi portafolio de automatización y procesamiento de datos.
